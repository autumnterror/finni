# Варианты иконки игровой валюты

Пять PNG 1254 × 1254 с прозрачным фоном. Они созданы через `image_gen` как отдельные варианты на основе первоначальных концептов. Палитра согласована с тёплой детской комнатой, коричневой обводкой и зелёными кнопками приложения. На монетах нет букв, цифр и знаков реальных валют.

| Файл | Вариант | Центральный знак |
|---|---|---|
| `01_classic_gold.png` | Классическое золото | Выпуклая пятиконечная звезда |
| `02_cream_enamel.png` | Светлая эмаль | Лапка питомца |
| `03_sage_enamel.png` | Зелёная эмаль | Четырёхлучевая искра |
| `04_playful_copper.png` | Медная кромка | Солнце с шестью лучами |
| `05_minimal_gold.png` | Лаконичное золото | Тиснёный круг без эмблемы |

Общий запрос для вариантов: сохранить круглую форму, фронтальный ракурс, мягкую книжную игровую иллюстрацию, чистую читаемую форму для маленького размера HUD и подлинный прозрачный фон. Изменить только центральный символ согласно таблице. Исключить текст, цифры, символы реальной валюты, квадратную подложку и лишние объекты.

Варианты пока не подключены к интерфейсу. Выбор иконки и размеры для Android будут определены после согласования.
