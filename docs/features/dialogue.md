# Feature: Общие карточки диалога

## Goal

Показывать короткие реплики поверх игровой сцены с портретом говорящего и понятным способом перехода между карточками.

## Educational Goal

Диалог сам не начисляет XP и не открывает достижения. Learning-модуль и игровые фичи могут использовать его для первого объяснения ситуации и последствий решения.

## Ownership

`core:designsystem` владеет видом модального окна, адаптивным расположением, подсказкой касания, счётчиком карточек и переходом по касанию. Вызывающая фича владеет текстом, персонажем, моментом показа и реакцией на завершение. `feature:pet` предоставляет цветной портрет текущего питомца через `PetApi.Portrait`.

## Modules

- `core:designsystem`: `FinPetDialogueDialog` и семантический размер портрета.
- `feature:pet`: области кадрирования четырёх видов и демонстрационный сценарий приветствия.
- `feature:game-session`: передаёт нажатие на питомца в pet-фичу.

## Domain Model

Диалог принимает непустой список строк. Индекс текущей карточки живёт в Compose-состоянии окна и не является игровой транзакцией.

## Dependencies

Компонент зависит только от Compose и токенов дизайн-системы. Он не знает о профиле питомца, learning-прогрессе, достижениях или хранилище.

## Provided Contracts

`FinPetDialogueDialog(speakerName, cards, portrait, onFinished)` позволяет любой фиче передать собственный портрет и последовательность реплик. `PetApi.Portrait(profile)` рисует мордочку выбранного вида и цвета для этого слота.

## UI

В верхней части сцены появляется модальная карточка с портретом, именем, текстом, счётчиком и подсказкой «Коснись экрана…». Сцена под карточкой не затемняется. Касание в любом месте окна открывает следующую карточку; последняя закрывает окно. Системная кнопка «Назад» завершает диалог. Область касания покрывает весь экран.

## Persistence

Карточка переживает пересоздание Compose через `rememberSaveable`. Приветствие не сохраняется в постоянный профиль: при обычном повторном запуске его можно открыть нажатием на питомца.

## Events

Создание питомца и нажатие на него отправляют одноразовую команду `ShowGreeting`. Завершение диалога скрывает окно. Денежных и игровых событий нет.

## Skill Integration

Достижения у общего компонента отсутствуют. Learning action, правило прогресса и feedback определяет вызывающая фича; показ карточки сам по себе не продвигает обучение.

## Configuration

Число и текст карточек передаются вызывающей фичей. Размеры, цвета и типографика берутся из `AppTheme`.

## Edge Cases

- Пустой список карточек отклоняется сразу.
- Длинный текст переносится в карточке; окно располагается с учётом safe area.
- Быстрые касания не выполняют финансовых или игровых операций.
- Внешнее касание обрабатывается тем же переходом, что касание карточки.

## Acceptance Criteria

- Приветствие появляется после создания питомца и по нажатию на него в комнате.
- Портрет соответствует каждому из четырёх видов и выбранному цвету.
- Learning-модуль и игровые фичи могут использовать компонент без зависимости дизайн-системы от pet-фичи.
- Подсказка и счётчик видимы на каждой карточке.
