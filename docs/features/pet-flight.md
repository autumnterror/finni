# Feature: Полёт питомца

Интеграция с рыбалкой: feature/flappy-bird-mini-game, 3957749. Изменение UX и правил по замечаниям пользователя.

## Цель и путь

Бесплатная аркада с питомцем, развивающая интерес к времени вместе. Без финансового XP, оплаты повторов или покупки преимуществ.

Комната (только рисунок змея) → полноэкранная сцена → 3–2–1 → автоматический полёт → компактный итог поверх сцены → повтор/рекорды/комната. Нет домашнего экрана, обязательной тренировки, Ready-ожидания, панелей или ручной паузы. Счёт справа сверху на фоне игры.

## Границы

This feature owns:
- симуляцию, препятствия, счёт, рекорды по правилам, значки;
- снимки восстановления, очередь подтверждённых эффектов и игровой UI.

This feature consumes:
- FlightHost: профиль, доступ, ресурс актуального питомца, настройки, эффект совместной игры;
- Room DAO/RoomTransactionRunner и GlobalNavigator из core.

This feature emits:
- сохранённый результат и запрос эффекта по sessionId;
- одноразовый сигнал прохода/посадки.

Экономика, уровень, потребности и кастомизация принадлежат общим доменам. App связывает контракты. Комната владеет зоной и её рисунком. Общая MiniGameAccess делает flight открытой, включая старые сохранения. Рыбалка независима.

## Состояние и сохранение

FlightSession содержит ID, профиль, rulesVersion, PRNG, tick, y/v, препятствия, очки, действия и исход. FlightProgress содержит active, records, badges, lastResult, pendingEffects. JSON schemaVersion=1 остаётся совместимой; rulesVersion=2 отделяет более сложные рекорды. Устаревший active очищается без изменения истории.

Снимки пишутся каждую активную секунду и при переходах; операции упорядочены, поздний checkpoint не откатывает новый. Итог/рекорд/значки/pending атомарны. Неизвестная схема и ошибка записи не сбрасывают профиль. Общая FinPetDatabase остаётся версии 9, новых миграций не требуется.

## UI и lifecycle

Состояния: Loading, Countdown, Playing, Saving, Results, Records, Locked, Error. Foreground — отдельное техническое свойство.

Back сохраняет и сразу возвращает в комнату. Уход в фон прекращает время и ввод, возвращение автоматически даёт 3 секунды подготовки. Обновление/восстановление завершённого результата сохраняет его и начинает новый полёт при входе из комнаты. Задержка кадра не вызывает экран паузы.

Сцена занимает окно целиком; только счёт учитывает safeDrawing inset. Рисунок неба можно обрезать, игровая геометрия полностью отображается. FinPetCard/Button и семантическая типографика используются в результате; никакого UI внутри PNG.

## Производительность

Фиксированный шаг 1/120с; кадр ограниченно догоняет время, остаток шага используется для рисования. Один снимок на кадр, без нескольких временных списков на шаг. Canvas читает координаты в draw. PNG декодируются и кэшируются вне main; прозрачные поля колонны не занимают GPU-текстуру. Room/JSON идут в IO, ToneGenerator работает на отдельном потоке.

## Проверки

Регрессии: старт без нажатия, блокировка ввода в отсчёте/фоне, возврат из фона, Back, устаревшие callback, ошибка сохранения, быстрый повтор. Физика: 30/60/90/120/144Hz, неизменность снимков, 1000 маршрутов, коллизия перед очком, точный финиш. Android: навигация обеих игр, отсутствие названия зоны и панелей, совпадение границ сцены и экрана, сохранения и реальные Choreographer-кадры.
