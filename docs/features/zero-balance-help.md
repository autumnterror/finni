# Feature: временная помощь при нулевом кошельке

## Цель

Когда доступный баланс достигает 0 ₽, ребёнок получает временную помощь родителей в размере 500 ₽. Комната показывает окно «Родители помогли тебе».

## Владение

`feature:economy` владеет проверкой нулевого кошелька и операцией пополнения. `feature:room` наблюдает за балансом, запрашивает помощь и показывает уведомление.

## Правила

- Помощь выдаётся только при точном нулевом доступном балансе.
- Одна попытка выдачи создаёт одну финансовую операцию `zero-balance-help:<номер>` с типом `zero_balance_help`.
- Одновременные проверки не могут создать два пополнения: операция выполняется внутри транзакции экономики.
- После нового расхода до 0 ₽ временная помощь может быть выдана снова.
- В текущем MVP помощь не создаёт обязательство, удержание или снижение прогресса.

## UI

Диалог содержит заголовок «Родители помогли тебе», сумму 500 ₽ и кнопку «Спасибо». Экран не использует слово «долг».

## Критерии приёмки

- При нулевом кошельке баланс становится 500 ₽ и появляется окно.
- Повторные события, пока баланс уже пополнен, не создают новых денег.
- Пополнение есть в истории финансовых операций и сохраняется после перезапуска.
