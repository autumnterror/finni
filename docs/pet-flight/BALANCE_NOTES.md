# Баланс полёта — правила 2

Схема файла остаётся 1, правила и рекорды — rulesVersion=2. Источник balance.v1.json совпадает с runtime assets/flight_balance.json.

## Физика

Фиксированный шаг h=1/120с: v'=min(v+1100h,460), y'=y+v'h. Взмах заменяет скорость на -320; интервал не менее 100мс. Автовзлёт не увеличивает счётчик действий игрока.

В непрерывном приближении подъём 320²/(2×1100)=46,5 единицы, вершина через 0,291с, возврат к исходной высоте через 0,582с. Фактический расчёт дискретный.

Мир 360×560, x питомца 90, старт y=280, мягкий радиус 14. Границы — края полного экрана, без полос сверху/снизу.

## Стадии

| Активное время | Скорость | Высота нового проёма |
|---|---:|---:|
| 0–20с | 145 | 146 |
| 20–40с | 168 | 134 |
| 40–60с | 192 | 122 |

Первый проём 160 по центру; последующие смещаются до 92 единиц, с отступом от края 55. Толщина колонны 58, расстояние 205. PRNG xorshift32 и его состояние сохраняются. Ширина существующего проёма при смене стадии не меняется.

По сравнению с правилами 1: скорость выше на 61–68%, последний просвет для центра уменьшен с 140 до 94, время между колоннами на последней стадии — 1,07с вместо 1,93с. Между задним и передним краем колонн остаётся 147/192≈0,77с на перестроение.

## Проверка и пределы

1000 seed завершены контроллером до 60с, минимум 48 очков. Контроллер без задержки читает координаты и делает взмах при снижении ниже центра ближайшего проёма на 18 единиц. Это проверяет проходимость маршрутов, но не обещает ребёнку финиш.

30/60/90/120/144Hz дают одинаковое число шагов. Группировка шагов и восстановление JSON сохраняют будущую траекторию. Столкновение раньше очка и финиша.

Задержки кадров учитываются до 100мс за кадр; больший разрыв отбрасывается, чтобы не телепортировать питомца через весь экран. Фон сбрасывает часы и автоматически запускает трёхсекундный отсчёт при возврате. Движение никогда не превращается в меню паузы из-за dt.

Баланс ещё требует наблюдения на телефоне с игроками. Менять физику/геометрию вместе с rulesVersion; арт и настройки не меняют рекорды.
