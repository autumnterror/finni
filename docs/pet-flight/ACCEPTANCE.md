# Приёмка «Полёта питомца»

| Проверка | Ожидаемый результат |
|---|---|
| Зона комнаты | Только рисунок змея, доступное имя «Полёт», без видимого текста и покупки |
| Первый/повторный вход | Сразу игровая сцена, 3–2–1, автоматический взлёт |
| Экран | Сцена совпадает с границами окна, никаких панелей сверху/снизу |
| HUD | Только счёт справа сверху поверх игры |
| Ввод в отсчёте | Не двигает питомца и не увеличивает действия |
| Новое касание | Взмах при down, до отпускания |
| Удержание/мультитач | Без автоматических повторов |
| Нет касаний после старта | Время идёт, попытка естественно заканчивается |
| Быстрые касания | Скорость заменяется, интервал 100мс соблюдается |
| Столкновение | Круг/прямоугольник, раньше очка и финиша |
| Проход | Ровно одно очко за всё препятствие |
| Стадии 20/40с | Скорость растёт, новые проёмы уже, старые не меняются |
| 1000 seed | Проходимы контроллером, случайность воспроизводима |
| 30/60/90/120/144Hz | Одинаковое число шагов; остаток сглаживает отрисовку |
| Длинный кадр | Ограниченное догоняние, без меню и телепорта на всё пропущенное время |
| Back во время игры/отсчёта | Сохранение и прямой возврат в комнату |
| Фон/потеря фокуса | Нет времени и ввода; при возвращении автоматические 3 секунды |
| Поворот/широкое окно | Мир сохранён, вся геометрия видна, питомец не растянут |
| Завершение | Компактный итог поверх той же сцены |
| «Ещё раз» дважды | Один новый UUID, один отсчёт, один navigation entry |
| Старая версия правил | Активная попытка прервана, история рекордов осталась |
| Старый кадр/снимок | Не меняет новую или завершённую попытку |
| Ноль/равный рекорд | Нет ложного нового рекорда |
| Ошибка хранения | Честный статус, повтор/выход; данные не сброшены |
| Повтор финализации/эффекта | Нет дублирования |
| Автовзлёт без действий | Нет числового эффекта совместной игры |
| Попытка ≥10с с действием | Общий эффект +3 с ограничением 100 |
| Валюта/XP/навыки | Не меняются |
| Неизвестная схема | Нет перезаписи |
| Звук выключен/уменьшение движения | Управление и результат не меняются |
| Проход в рыбалку | Прежняя навигация работает |
| Renderer | Bitmap/пути не декодируются каждый кадр, физика не перестраивает Compose-экран |
| Работа main | Сохранение, PNG и ToneGenerator выполняются вне main |

Фактические проверки и ограничения: [VALIDATION.md](VALIDATION.md).
