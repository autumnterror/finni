# Графика «Облачная тропа»

Вместо геометрического фона используется оригинальный пиксельный небесный пейзаж: облака, воздушные острова, спокойный центр. Движущиеся колонны используют отдельный прозрачный спрайт песчаника с травяной кромкой. Питомец — прежний ресурс комнаты через FlightHost.

## Слои

1. Кэшированный фон на всё окно с ContentScale.Crop.
2. Текстурные колонны в координатах коллизии.
3. Короткий след и питомец с сохранением пропорций.
4. Счёт справа сверху и отсчёт поверх игры.
5. Компактный результат поверх остановившейся сцены.

В PNG нет текста, HUD, счёта или персонажа. Системные панели скрывает существующая MainActivity. У игрового поля нет внешних панелей.

## Ресурсы

- room_zone_flight: прежний рисунок змея, без текстовой подписи в комнате.
- img_flight_sky_v2.png: новый фон.
- img_flight_pillar_v2.png: новая колонна RGBA.
- pet_current: действующий питомец, декодируется под спрайт до 256px.

Встроенный image_gen; точные промпты и пути: [ART_REFRESH.md](../../feature/mini-games/flight/ART_REFRESH.md). Генерированные оригиналы скопированы в модуль без изменения файлов.

## Подготовка и рендеринг

FlightArtwork декодируется вне main. Прозрачные поля колонны удаляются из рабочей bitmap в памяти один раз. Рисуется источник без полей; верхняя колонна перевёрнута, трава обращена к проёму. Текстура обрезается по высоте и повторяет камень только при необходимости; изображение не сплющивается до высоты короткого препятствия.

Геометрия мира проецируется на полное окно по двум осям. Питомец масштабируется равномерно. Декоративное небо можно обрезать, коллизии — нельзя. Наклон -18…28°, без вращений и тряски. Reduced motion убирает наклон и след.

Цвета fallback-сцены и типографика счёта/отсчёта принадлежат design system. Цель — простая замена арта без изменения физики. Проверки: полноэкранность, отсутствие текста в комнате, пропорции персонажа, совпадение кромок колонн и проёмов, кадры Android.
