# Полёт питомца FinPet — v1
**Облачная тропа:** собственный питомец поднимается от нажатия и пролетает между парящими островками. Один короткий маршрут, личный рекорд, три значка и бесплатные повторы.

Полное описание теперь находится внутри модуля: [Полёт питомца FinPet — v1](../../feature/mini-games/flight/README.md).

Заимствован только общий принцип tap-to-fly. Персонажи, трубы, графика, название и уровни Flappy Bird не используются.
Это новый дизайн FinPet; файлы рыбалки и соседний чат использованы как пример глубины проработки, а не как инструкции выполнить работу над рыбалкой.

Решения первой версии: максимум 60 активных секунд; столкновение завершает попытку без наказания; один режим с автоматическим стартом после 3–2–1; основной результат — число пройденных проёмов; никакой валюты/финансового XP; общий эффект совместной игры за естественную попытку с ≥10 активными секундами и действием, независимо от очков.

Сцена использует ресурс питомца комнаты через host, новое пиксельное небо и текстуру колонн. Точные промпты обновления: feature/mini-games/flight/ART_REFRESH.md. Для входа из комнаты сгенерирован воздушный змей на прозрачном фоне; ресурс включён в модуль комнаты.

Актуальный UX от 7 сентября: рисунок змея без подписи → сразу полноэкранная сцена → 3–2–1 → автоматический взлёт. Счёт справа сверху, без панелей и ручной паузы. Повтор доступен в компактном результате.

## Реализация

Модуль `:feature:mini-games:flight` внедрён в `feature/flappy-bird-mini-game` поверх `1534133` с готовой рыбалкой. Первичная реализация велась отдельно в `feature/pet-flight-mini-game`. Подключены бесплатный вход из комнаты, навигация, сохранение и единый эффект совместной игры для обеих мини-игр.

Проверки интеграции: 108 тестов обеих игр и общего состояния, 1000 маршрутов полёта, сборка APK и lint без ошибок. Игровые наблюдения с детьми и проверка на физическом телефоне остаются следующим этапом.

Сборка для установки рядом с основной: `./gradlew :app:assembleDebug -PflightPreview=true`. Её applicationId — `github.detrig.internetbooster.flightpreview`. Для обычной сборки параметр не нужен. В обеих сборках полёт пока открыт сразу: войти в центральную секцию комнаты и нажать на воздушного змея справа от питомца. Покупка не требуется.

Миграция 8→9 сохраняет прогресс как основной рыбалки, так и раннего preview полёта; детали — в [описании интеграции](INTEGRATION.md).

Снимки исходной версии в screenshots/01–10 сохранены как история; актуальные начинаются с v2-.
