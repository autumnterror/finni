# Полёт питомца — бизнес-требования v1

ID flight, локация cloud_trail, правила 2. Эта редакция заменяет прежние требования к меню, тренировке перед стартом, паузе и вписанной сцене.

## Продукт

Короткая аркада с действующим питомцем FinPet для детей 7–11 лет. Нажатие поднимает питомца, между нажатиями он опускается. Цель — проходить между воздушными каменными колоннами. Столкновение нейтрально заканчивает попытку без наказания, потери денег или грустных обвинений.

Мини-игра — бесплатное время вместе. Финансовая компетентность не зависит от рекорда реакции. Никаких монет, XP, платного продолжения, рекламы, энергии, обязательных серий заходов.

## Вход и полноэкранный UI

- В комнате только сгенерированный рисунок воздушного змея, без текстового названия. Семантическое имя сохранено для доступности.
- Игра пока открыта всем по общей MiniGameAccess. Цена 300 зарезервирована и не списывается.
- Нажатие сразу открывает сцену. После готовности сохранения и текстур — 3–2–1 и автоматический взлёт.
- Нет домашнего меню, тренировки перед стартом, ожидания первого взмаха, отдельной кнопки взмаха, верхней/нижней панели или ручной паузы.
- Сцена заполняет всё окно; счёт отображается справа сверху поверх фона с учётом выреза экрана.
- Подсказка управления видна только при отсчёте. Нажатия во время него не действуют.
- Результат — компактная карточка поверх замершей сцены: счёт, рекорд, фактическое счастье, повтор, рекорды, комната. Повтор в том же navigation entry.
- Настройки звука/отклика/уменьшения движения доступны из рекордов после попытки.

## Управление и правила

Каждое новое касание задаёт скорость вверх. Ввод обрабатывается при down; удержание и дополнительные пальцы не дают автоповтора. Семантическая активация сцены делает тот же взмах. Автовзлёт не считается действием игрока.

Одна попытка до столкновения или 60 активных секунд. Очко — только после прохождения всего препятствия. Круг/прямоугольник, приоритет: столкновение → очко → финиш. Питомец узнаваем, хвост и гребень не являются дополнительными коллайдерами.

Более сложная версия: скорость 145/168/192; проёмы 146/134/122; первый 160; расстояние 205; толщина 58; перепад центров до 92. Геометрия и случайность настраиваются JSON, PRNG сохраняется. Уже появившийся проём не меняет размер.

## Lifecycle и результат

Back сразу возвращает в комнату с сохранением. Фон/потеря фокуса замораживают физику и ввод, возвращение автоматически запускает отсчёт 3–2–1. Нет экрана паузы и требования нажать «Продолжить». Кадровый разрыв ограниченно догоняется, не открывая меню.

Новый рекорд — строго больший положительный результат. Равенство сохраняет прежнюю дату; ноль не объявляется новым рекордом. История разделена по rulesVersion, прежние рекорды доступны. Значки за 1/10 проёмов и финиш остаются в прогрессе.

Естественная попытка с минимум одним действием и ≥10 активными секундами может дать +3 счастья, ограниченное 100. Общий домен применяет результат по sessionId один раз. Остальные потребности, деньги, навыки и уровень не меняются.

## Сохранение и ошибки

Снимок каждую активную секунду, при уходе в фон/комнату и финализации. Старые callback не откатывают новую сессию. Итог, рекорд, значки и pending effect атомарны; эффект доставляется отдельно и идемпотентно.

После остановки процесса активный снимок восстанавливается с отсчётом. После обновления rulesVersion устаревшая попытка прерывается без награды, рекорды остаются. Если восстановлен уже завершённый снимок, его результат сохраняется, а вход из комнаты начинает новую попытку.

Ошибка записи показывает повтор и выход с сохранением последней успешной версии. Неизвестная schemaVersion не перезаписывается. Никаких сбросов профиля.

## Качество

PNG декодируются вне главного потока и кэшируются. Размер текстуры питомца уменьшается под спрайт. UI не перестраивается по координатам каждого кадра. Физика 120 шагов/с; 30/60/90/120/144Hz дают одинаковое активное время. AudioTrack и сохранение не выполняются внутри кадра main.

Результат доступен крупному шрифту и TalkBack; аркада требует пространственного восприятия, полная доступность незрячему игроку не заявляется. Все существенные состояния понятны без звука. Настройки снижения движения сохраняют физику.

Автоматические тесты и эмулятор не заменяют наблюдения на физических устройствах и детский плейтест.
