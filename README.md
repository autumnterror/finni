# FinPet

FinPet — Android-игра о виртуальном питомце и обращении с деньгами для детей 7–11 лет. Игрок заботится о питомце, получает игровую валюту, планирует бюджет на неделю, покупает необходимое и желаемое, копит на цель и принимает решения в финансовых ситуациях. Игра показывает последствия выбора и помогает учиться на ошибках без стыда и наказаний.

Основной цикл: карманные деньги → недельный план → семь игровых дней → покупки, забота о питомце и финансовые события → сравнение плана с фактом → обратная связь и развитие питомца. Главный экран — квартира с интерактивными предметами.

## Быстрый запуск

### Требования

- Android Studio с поддержкой Android Gradle Plugin проекта;
- JDK 21;
- Android SDK Platform 36;
- эмулятор или Android-устройство с API 26 или новее.

При первой синхронизации Gradle скачает wrapper и зависимости. SDK можно настроить в Android Studio или указать локально в `local.properties`.

### Запуск из Android Studio

1. Откройте корень репозитория как Android Studio project.
2. Дождитесь синхронизации Gradle.
3. Выберите конфигурацию `app` и запущенный эмулятор или подключённое устройство.
4. Нажмите **Run**.
5. При первом запуске выберите игровой или демонстрационный режим. В демонстрационном режиме в телефоне питомца доступно меню для ускоренного просмотра игрового цикла.

### Сборка и установка debug APK

Windows PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:installDebug
```

macOS или Linux:

```bash
./gradlew :app:assembleDebug
./gradlew :app:installDebug
```

Для установки запустите эмулятор или подключите устройство с включённой USB-отладкой. APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

Собрать release-вариант:

```powershell
.\gradlew.bat :app:assembleRelease
```

В macOS/Linux используйте `./gradlew :app:assembleRelease`. В текущей конфигурации ключ подписи не задан, поэтому получится неподписанный APK; для распространения релиз нужно подписать локальным ключом, который не следует добавлять в репозиторий. Публикация в RuStore пока не заявляется.

### Технические и пользовательские требования ТЗ

- **Android 8.0+ и портретная ориентация — реализовано:** `minSdk = 26`, ориентация закреплена в манифесте.
- **Локальные данные и отсутствие обязательной регистрации — реализовано:** используется локальная база; обязательный игровой путь не просит реальные банковские или контактные данные.
- **Разрешения — ограничены текущими функциями:** в манифесте объявлены `INTERNET` (сетевой API мини-игр) и `POST_NOTIFICATIONS` (уведомление о голоде). Разрешения камеры, микрофона, контактов и геолокации не объявлены.
- **Отсутствие реальных платежей и рекламы — соответствует текущему коду:** внутриигровые рубли не являются реальными деньгами; интеграций рекламных и платёжных SDK в проекте не найдено.
- **Доступность и работа без сети — частично проверены:** есть озвучивание настроек, семантические подписи отдельных элементов и локальное хранение ключевого состояния. Полный аудит контраста, системного увеличения шрифта, размера всех нажатий, отключения анимаций и прохождения основного цикла без сети не зафиксирован.
- **Проверка на физическом устройстве, экране от 360 dp и производительности запуска/отклика — не подтверждена этим README.** Нужен отдельный прогон на устройстве с RAM от 3 ГБ и фиксация результатов.
- **Подписанный release APK — пока не подготовлен:** Gradle release signing config отсутствует. Для промежуточного запуска используйте debug APK из инструкции выше.
- **Полный реестр лицензий на сторонние библиотеки, изображения, шрифты и звуки — не собран в одном документе.** В репозитории есть [`LICENSE`](LICENSE) и отдельные материалы по ресурсам.
