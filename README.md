# FinPet

FinPet — Android-игра о виртуальном питомце и разумном обращении с деньгами для детей 7–11 лет. Игрок заботится о питомце, получает карманные деньги, планирует расходы на неделю, покупает нужные и необязательные вещи, копит на цели и принимает решения в финансовых ситуациях. Игра показывает последствия выбора и помогает учиться на них без стыда и наказаний за ошибки.

Главный игровой цикл — неделя: карманные деньги → финансовый план → семь игровых дней с заботой о питомце и событиями → сравнение плана с расходами → обратная связь и развитие питомца. Основной экран — квартира с интерактивными предметами: телефон, блокнот, копилка, шкаф, холодильник, стол, кровать и ванна.

## Состав репозитория

Это многомодульный Android-проект на Kotlin. `settings.gradle.kts` содержит полный список Gradle-модулей.

| Путь | Назначение |
| --- | --- |
| `app/` | Точка входа приложения, сборка APK и интеграция функций. |
| `core/` | Общая инфраструктура и переиспользуемые компоненты: дизайн-система (`designsystem`) и каталог товаров (`products`). |
| `feature/` | Игровые функции, разделённые по Gradle-модулям: экономика, недельный цикл и планирование, состояние игры и питомца, квартира, магазин и покупки, накопления, обучение и задания, телефон, инвентарь, холодильник и гардероб. |
| `feature/mini-games/` | Общий модуль мини-игр и игры Fishing и Flight. |
| `docs/` | Спецификации функций, дизайн-материалы, исследования и прототипы. |
| `guides/` | Заметки по архитектуре и соглашениям проекта. |
| `art/` | Графические ресурсы игры. |
| `scripts/`, `tools/` | Вспомогательные скрипты для ресурсов и разработки. |
| `gradle/` | Версии зависимостей, настройки Gradle и wrapper. |
| `AGENTS.md` | Общий продуктовый и архитектурный контракт проекта. |

Функции в `feature/` включают модули `product-market`, `shop`, `game-session`, `game-state`, `economy`, `week`, `planning`, `learning`, `learning-tests`, `savings`, `room`, `pet`, `phone`, `inventory`, `fridge` и `wardrobe`.

## Быстрый запуск

### Требования

- Android Studio с поддержкой Android Gradle Plugin из проекта;
- JDK 21 (Gradle Wrapper настроен на Java 21);
- Android SDK Platform 36 и эмулятор или устройство с Android 8.0 (API 26) или новее.

При первом запуске Gradle может скачать нужные версии Gradle, JDK и зависимостей. Для сборки настройте SDK в Android Studio или укажите путь к нему в локальном `local.properties`.

### Запуск из Android Studio

1. Откройте корневую папку репозитория как проект.
2. Дождитесь синхронизации Gradle.
3. Выберите конфигурацию `app` и эмулятор или подключённое Android-устройство.
4. Нажмите **Run**.

При первом запуске выберите игровой или демонстрационный режим. В демонстрационном режиме в телефоне питомца доступно меню для быстрого просмотра возможностей игры.

### Сборка и установка из терминала

Windows PowerShell:

```powershell
./gradlew.bat :app:assembleDebug
./gradlew.bat :app:installDebug
```

macOS или Linux:

```bash
./gradlew :app:assembleDebug
./gradlew :app:installDebug
```

Для `installDebug` запустите эмулятор или подключите устройство с включённой отладкой по USB. Собранный debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
