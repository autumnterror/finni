# Питомец

Модуль владеет созданием, сохранением и единым 2D-представлением питомца. Для MVP доступны кошка, собака, крыса и петух, четыре цвета и имя длиной до 10 символов.

Публичный `PetApi` предоставляет:

- наблюдение за текущим профилем;
- first-run gate с экраном создания;
- Compose-контент актуального питомца;
- составной bitmap актуальной внешности для игровых Canvas-сцен.

`game-session` использует gate перед комнатой и передаёт питомца в её pet-слот. Рыбалка и полёт получают тот же профиль через `PetApi`; фиксированного drawable или отдельной глобальной `PetAppearance` больше нет.

Внешность хранится в простом локальном storage модуля. Сытость, счастье и остальной игровой прогресс по-прежнему принадлежат `game-state`. Подробная спецификация находится в `docs/features/pet.md`.
