# Игровая сессия

Модуль предоставляет корневой экран игры и объединяет UI комнаты и питомца. Баланс, показатели питомца, покупки и БД принадлежат `game-state`; `game-session` отвечает за композицию и навигацию.

`GameSessionRoute.Home` — корневой маршрут Navigation 3. `gameSessionGraph` регистрирует экран, `GameSessionApi.openGameSession()` открывает сессию. Зависимости передаются ручным DI через `GameSessionMediator` из `app`.

`GameSessionScreen` получает `RoomApi` и `PetApi`, не открывает комнату до создания питомца и встраивает `RoomApi.Content` в полноэкранный `GameSessionHome`. В слот `petContent` передаётся UI сохранённого профиля с выбранными видом, цветом и спокойной idle-анимацией. Координаты, направление, масштаб и догоняющее движение задаёт непрерывная сцена `room`.

Общий неподвижный HUD выводит `room` из реальных данных `game-state`. Оставшиеся в `game-session` ViewModel, форматтеры и старые компоненты HUD текущий экран не использует.

Показатели потребностей питомца остаются в `game-state`. Идентичность, кастомизация, сохранение профиля и общий 2D-рендер принадлежат `feature:pet`.

`FinPetTheme` применяется в Activity через `ProvideAppContent`, UI использует `AppTheme`. Портретная ориентация, edge-to-edge, скрытие системных панелей и тема без ActionBar настраиваются в `app`. Главный экран не добавляет внешние отступы фону; безопасные отступы HUD определяет комната.
